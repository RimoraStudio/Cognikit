# Button notes

- This is an illustrative React API, not a prescribed product-wide button
  library. Preserve the target application's variants and prop contract.
- The preview simulates a local save state only; it makes no network request and
  persists no data.
- The button's brief press response is its component-specific motion. Do not
  copy that press treatment onto fields or overlays.
- The framework-neutral counterpart is `examples/button/`.
