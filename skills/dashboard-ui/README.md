# Dashboard UI

Design data-dense dashboards, admin panels, and internal tools that answer questions rather than decorate. Audience archetypes and KPI selection process, question-first hierarchy, chart selection rules, data table discipline, widget states, filters, density, and anti-patterns for dashboard design.

## When to use

Use it for data-dense dashboards, admin panels, metrics pages, operational tables, filters, or chart selection.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/dashboard-ui --global --yes
```

## Package contents

- `SKILL.md`: complete agent instructions
- `evals/evals.json`: sample prompts for checking skill behavior
