# API Design

Design REST API contracts before implementation: resource modeling, route conventions, request/response shapes, error codes, pagination, idempotency, and versioning. Produces consistent, predictable API contracts that respect existing codebase conventions.

## When to use

Use it before implementation to define REST resources, routes, payloads, errors, pagination, idempotency, or versioning.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/api-design --global --yes
```

- `SKILL.md`: complete agent instructions
- `evals/evals.json`: sample prompts for checking skill behavior
