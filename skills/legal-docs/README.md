# Legal Docs

Draft professional-grade privacy policies, terms of service, cookie policies, refund policies, and acceptable use documents. Intake-driven drafting matched to actual data practices with jurisdiction-aware clauses (GDPR, CCPA, COPPA).

## When to use

Use it to draft or update a product privacy policy, terms, cookie or refund policy, disclaimer, data processing agreement, or acceptable use policy from the product's actual practices.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/legal-docs --global --yes
```

## Package contents

- `SKILL.md`: complete agent instructions
- `evals/evals.json`: representative intake and drafting prompts
