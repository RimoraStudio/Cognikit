# Design System Architecture

Build, scale, audit, and govern a design system as an engineering product. Covers token architecture, governance models, contribution tiers, versioning, deprecation, drift detection, multi-brand orchestration, Figma-to-code pipelines, CI gates, and AI-agent readiness.

## When to use

Use it to engineer and govern a design system: token pipelines, contribution rules, versioning, deprecation, drift checks, or multi-brand architecture.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/design-system-architecture --global --yes
```
