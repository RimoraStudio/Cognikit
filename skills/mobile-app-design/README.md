# Mobile App Design

Design mobile app UIs that respect platform conventions instead of shrunken web pages. Four layers: pre-work (MFRI risk index, design bible locking), platform and navigation (iOS HIG vs Material 3, deep links, predictive back), visual design (60/30/10 color, 8-pt grid, system fonts, OLED dark mode, haptics), and execution (states, Peak-End rule, user-stage personalization, performance patterns, anti-AI-tells, 33-point quality checklist).

## When to use

Use it when designing iOS or Android app flows, navigation, touch targets, platform-specific controls, or mobile interaction behavior.
