# App Store Compliance Router

> Deprecated compatibility skill. Use `apple-app-store-compliance` and `google-play-compliance` for new work.

Routes platform-specific store compliance tasks to Apple App Store or Google Play specialists. Use when the platform is unclear or both stores need review.

## When to use

This package is deprecated and retained for existing installs. For new work, use the Apple or Google Play specialist directly; use both for a cross-platform review.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/app-store-compliance --global --yes
```
