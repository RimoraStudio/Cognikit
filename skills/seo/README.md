# SEO

Audit and implement technical and on-page SEO to professional standard. Meta tags, canonicals, robots and sitemap rules, JSON-LD structured data, Open Graph, Core Web Vitals, EEAT signals, and anti-slop content checks.

## When to use

Use it to audit or implement crawlability, indexing, metadata, canonicals, robots and sitemap rules, structured data, social tags, or Core Web Vitals.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/seo --global --yes
```

## Package contents

- `SKILL.md`: complete agent instructions
- `evals/evals.json`: representative audit and implementation prompts
