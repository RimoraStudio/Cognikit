# Apple App Store Compliance

Audit Apple-platform apps against App Review Guidelines, App Store Connect requirements, privacy and business rules; diagnose rejections and prepare factual responses. Covers guideline mapping, 2.3.10 screenshots, 3.2 distribution, and current-source verification.

## When to use

Use it for Apple-platform App Review, App Store Connect, TestFlight, distribution, rejection responses, or Apple-specific privacy and policy checks.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/apple-app-store-compliance --global --yes
```

## Package contents

- `SKILL.md`: complete agent instructions
- `references/policy-map.md`: detailed guidance loaded when needed
- `evals/evals.json`: sample prompts for checking skill behavior
