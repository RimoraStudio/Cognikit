# Marketing Sites

Design and write marketing and landing pages that convert without looking AI-generated. Narrative arc, hero variations, conversion copy rules, pricing page patterns, one-memorable-element discipline, and an anti-slop blocklist for generic landing page patterns.

## When to use

Use it to plan or write a conversion-focused marketing page, landing page, launch or waitlist page, product page, or pricing page.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/marketing-sites --global --yes
```

## Package contents

- `SKILL.md`: complete agent instructions
- `evals/evals.json`: sample prompts for checking skill behavior
