# RAG Pipelines

Build retrieval-augmented generation systems: document ingestion, structure-aware chunking, embeddings, vector store selection by scale, hybrid retrieval, grounded answer generation with citations, multi-tenant isolation, and evaluation of retrieval hit-rate vs answer faithfulness.

## When to use

Use it to build document ingestion, chunking, embedding, retrieval, and grounded-answer pipelines with citations.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/rag-pipelines --global --yes
```

## Package contents

- `SKILL.md`: complete agent instructions
- `evals/evals.json`: sample prompts for checking skill behavior
