# Primary sources

Verify current endpoints, model availability, limits, dimensions, pricing, and supported query features in vendor documentation before selecting an implementation.

- OpenAI embeddings guide: https://developers.openai.com/api/docs/guides/embeddings
- OpenAI embeddings API reference: https://developers.openai.com/api/reference/resources/embeddings
- Ollama embeddings documentation: https://docs.ollama.com/capabilities/embeddings
- pgvector documentation: https://github.com/pgvector/pgvector
- Qdrant documentation: https://qdrant.tech/documentation/
- Chroma documentation: https://docs.trychroma.com/

These are candidate references, not endorsements or permanent defaults. Evaluate retrieval quality and operational fit on the target corpus.
