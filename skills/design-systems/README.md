# Design Systems

Choose and implement the right visual design system for any app or website. Brief-inference read with variance/motion/density dials, 14 design systems with when-to-use guidance plus buy-vs-build routing, a variance engine for non-repeating directions, 122 anti-AI-slop rules, component patterns (double-bezel cards, gapless bento, magnetic hover, micro-UIs), AIDA page structure, audit-and-upgrade workflow, DESIGN.md spec generation, anti-drift conventions, and UX psychology laws with a dark-pattern guardrail.

## When to use

Use it to choose or refine a product's broad visual direction, select a design system, audit a site-wide UI, or write a `DESIGN.md` specification.
