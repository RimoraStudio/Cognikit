# Primary sources

Check these sources and the versions supported by the target client before using SDK syntax or protocol behavior in a new implementation.

- MCP specification and revision history: https://modelcontextprotocol.io/specification
- Official TypeScript SDK and v1-to-v2 migration guide: https://github.com/modelcontextprotocol/typescript-sdk
- Official Python SDK and release notes: https://github.com/modelcontextprotocol/python-sdk
- MCP Apps extension documentation: https://modelcontextprotocol.github.io/ext-apps/
- MCPB packaging project and manifest schema: https://github.com/anthropics/mcpb

The core protocol, SDK releases, and host-specific extensions have separate compatibility timelines. Verify each independently.
