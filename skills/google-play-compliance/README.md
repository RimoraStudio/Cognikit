# Google Play Compliance

Audit Android apps against Google Play Developer Program Policies and Play Console requirements; diagnose rejections and enforcement, reconcile Data safety, permissions, billing, ads, target API, and prepare evidence-based appeals.

## When to use

Use it for Android app review, Google Play policy, Play Console, Data safety, permissions, billing, enforcement, or rejection responses.

## Install

```sh
npx skills add RimoraStudio/cognikit/tree/main/skills/google-play-compliance --global --yes
```

## Package contents

- `SKILL.md`: complete agent instructions
- `references/policy-map.md`: detailed guidance loaded when needed
- `evals/evals.json`: sample prompts for checking skill behavior
